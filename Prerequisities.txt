AICorellator — Prerequisites
============================

Core requirements
-----------------

Python 3.11+
    Required for the core pipeline, normalizers, and CLI.
    Check: python3 --version

pip / uv
    For installing dependencies.
    uv is recommended (faster, isolates environments):
        curl -LsSf https://astral.sh/uv/install.sh | sh

Git
    For cloning the repository and pulling external tool wrappers.
    Check: git --version


External tools (must be installed separately)
---------------------------------------------

AICorellator does not bundle discovery or scanning tools.
It consumes their output. Install the ones you plan to use.

NeuralScan
    Discovery of local LLM endpoints and MCP servers.
    Install: npm install -g neuralscan
    Check:   neuralscan --version

agent-bom
    Package inventory, CVE lookup, credential blast radius.
    Install: uv pip install agent-bom
    Check:   agent-bom --version

agent-audit-kit
    MCP config scanning, tool poisoning detection, secret exposure,
    supply chain analysis. Fully offline, no API keys required.
    Install: uv pip install agent-audit-kit
    Check:   agent-audit-kit --help

garak
    LLM behavioral scanner (prompt injection, jailbreak, encoding).
    Install: uv pip install garak
    Check:   garak --version


Local LLM runtime (for the analysis layer)
------------------------------------------

AICorellator uses local LLMs to correlate graph data into attack chains.
One of the following is required:

Ollama (recommended for macOS / Apple Silicon)
    Install: brew install ollama
    Start:   ollama serve
    Pull:    ollama pull qwen3.5:9b

vLLM (recommended for Linux / NVIDIA)
    Install: pip install vllm
    See vLLM docs for serving a model.

LM Studio (GUI alternative)
    Download from https://lmstudio.ai
    Load a model and enable the local server.


Hardware guidance
-----------------

Minimum:
    16 GB RAM, 8 GB VRAM (or unified memory)
    Supports a single 7B–9B model in 4-bit quantization.
    Suitable for the "fast" profile.

Recommended:
    64 GB unified memory (Apple Silicon) or 24 GB VRAM (NVIDIA)
    Supports 27B–32B models in 4-bit, and sequential loading of
    multiple heterogeneous models for the "deep" profile.

Storage:
    1–5 GB per scan directory, depending on graph size and raw
    tool output volume. Plan for history retention.


Optional
--------

Docker
    Required only if you want to run OWASP FinBot CTF locally
    as a test target.
    Check: docker --version

OWASP FinBot CTF
    Local test target for validating the pipeline end-to-end.
    Clone:  git clone https://github.com/GenAI-Security-Project/finbot-ctf
    Run:    docker compose up


Network access
--------------

AICorellator itself does not require network access.
However, some external tools may:
    - NeuralScan:         no
    - agent-bom:          yes (CVE databases)
    - agent-audit-kit:    no
    - garak:              no (unless using remote API targets)

For air-gapped environments, verify each tool's offline behavior
before relying on it.


What is NOT required
--------------------

- Database (PostgreSQL, SQLite, etc.)
- Message broker (Redis, RabbitMQ)
- Cloud credentials
- Root / administrator privileges
